**Web原稿合宿専用**
# お手軽小説執筆NOTE


ブラウザだけで使える、小説執筆・原稿管理Webアプリケーションです。

作品ごとの原稿を管理しながら、文字数・目標文字数・執筆時間などを確認できます。
原稿の保存やバックアップにも対応しており、手軽に執筆環境を整えられます。

## 公開ページ

公開ページはこちらです。

https://web-writing-app.netlify.app/

## 主な機能

### 作品管理

- 新しい作品の作成
- 作品情報の編集
- 作品の削除
- 作品の複製
- 作品一覧の並び替え
- 作品ごとの目標文字数設定
- 執筆開始・終了時刻の記録
- プロット・メモの保存

### 執筆エディタ

- ブラウザ上での小説執筆
- 自動保存
- Enterキーによる改行・段落処理
- 記号・括弧の入力補助
- 選択範囲を括弧で囲む入力補助
- 行頭の全角スペースを扱うための入力補助
- Undo / Redo
- 文字数のリアルタイム表示

### 執筆状況

- 現在の文字数
- 目標文字数
- 目標に対する進捗率
- 目標を超えた場合の進捗表示
- 執筆時間の計測
- カウントダウンタイマー

### 文字設定

アプリ全体の執筆フォントを変更できます。

- ゴシック
- メイリオ
- 游ゴシック
- 明朝

文字サイズも変更できます。

### データ管理

作品データはブラウザに保存されます。

作品データの持ち出しやバックアップのため、以下の機能があります。

- 全データをバックアップ
- 全データを復元
- 作品を書き出す
- 作品を読み込む
- 読み込み時の作品の重複・競合への対応
- 原稿をTXT形式で書き出す

「全データをバックアップ」では、保存されている作品をまとめてバックアップできます。

作品単位で持ち出したい場合は、「作品を書き出す」を利用できます。

### キーボード・タッチ操作

PCでのキーボード操作に加え、スマートフォンなどのタッチ操作でも利用できるようにしています。

## 使い方

### 1. 新しい作品を作る

トップ画面から「＋ 新規プラン作成」を選択し、作品情報を登録します。

### 2. 執筆を開始する

作品一覧から作品を選択し、「原稿合宿を開始」から執筆画面を開きます。

執筆中は、文字数や目標文字数、執筆時間などを確認できます。

### 3. プロット・メモを利用する

作品ごとにプロットやメモを保存できます。

執筆前の構成整理や、執筆中の覚え書きなどに利用できます。

### 4. 原稿を書き出す

完成した原稿はTXT形式で書き出せます。

また、作品単位で「作品を書き出す」を利用して、作品データを保存することもできます。

### 5. データをバックアップする

「作品データ管理」から「全データをバックアップ」を利用できます。

大切な原稿は、定期的にバックアップしておくことをおすすめします。

バックアップしたデータは、「全データを復元」から戻すことができます。

## データについて

作品データは、使用しているブラウザに保存されます。

別のブラウザや別の端末で同じ作品を利用する場合は、「全データをバックアップ」や「作品を書き出す」機能を利用してください。

ブラウザのデータを削除した場合などには、保存されている作品データも失われる可能性があります。

大切な原稿は、定期的に「全データをバックアップ」して保存してください。

## 動作環境

JavaScriptが利用できる現行Webブラウザで利用できます。

PC・スマートフォンでの利用を想定しています。

ブラウザや端末によって、表示や入力操作が異なる場合があります。

## コンセプト

「Web原稿合宿専用」をコンセプトに、原稿を書くために必要な機能をひとまとめにした執筆環境を目指しています。

実際の宿泊型の原稿合宿をイメージしながら、

- 今日はどこまで書くか
- 目標文字数まであとどれくらいか
- どのくらいの時間を書いたか

といった執筆状況を確認しながら原稿を書けることを目指しています。

- 執筆実績の蓄積
