# Web旅館 ゆけむり

「Web旅館 ゆけむり」は、執筆合宿をモチーフにしたブラウザ完結型の小説執筆・原稿管理Webアプリケーションです。旅館にチェックインするような感覚で、集中して執筆作業を行えます。

## 主な機能

- **宿泊プラン形式の原稿管理**: 作品ごとに目標文字数、チェックイン・チェックアウト日時を設定可能。
- **快適なエディタ環境**:
  - 行頭の自動字下げ（「」や『』、――などの記号挿入時は自動でスペースを調整）
  - ワンタップで使える記号ボタンバー
  - リアルタイム文字数・進捗率・残り時間の表示
- **モチベーション維持機能**: 2500文字ごとに発生する達成ポップアップ（ON/OFF切替可能）
- **プロット・メモ機能**: 作品ごとにプロットを常時確認・編集可能
- **データ永続化と移行**: 
  - ブラウザの `localStorage` による自動保存
  - JSON形式による全データのバックアップおよび復元機能
  - テキストファイル（.txt）での原稿書き出し

## 使い方

1. ロビー画面の「＋ 新規プラン作成」から作品名や目標字数、チェックイン日時を設定して合宿を開始します。
2. 執筆部屋で本文やプロットを入力します（15秒ごとに自動保存されます）。
3. 「txt書き出し」や「JSONバックアップ」でデータの保存・出力が行えます。

## 動作環境

モダンブラウザ（Google Chrome, Safari, Firefox, Edge など）のスマートフォン・PC環境に対応しています。
