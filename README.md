# かんづめの宿 「かんづめの宿」は、執筆合宿をモチーフにしたブラウザ完結型の小説執筆・原稿管理Webアプリケーションです。 作品ごとに目標文字数やチェックイン・チェックアウト日時を設定し、旅館に滞在するような感覚で集中して原稿を書くことができます。 ## 主な機能 - **作品管理** - 作品の新規作成・編集・削除 - 作品ごとの目標文字数設定 - チェックイン・チェックアウト日時の設定 - 作品一覧の並び替え（▲▼） - 作品ごとのプロット・メモ保存 - **執筆エディタ** - ブラウザ上で本文を直接執筆 - Enterで「改行＋行頭全角スペース」を自動挿入 - 「――」「……」「「」」「『』」「（）」の記号・括弧入力 - 行頭の全角スペースを考慮した記号入力 - 選択範囲を括弧で囲む操作 - 本文のUndo / Redo - PCのキーボードショートカットによるUndo / Redo - **執筆状況** - リアルタイム文字数表示 - 目標文字数に対する進捗率表示 - 目標文字数を超えた場合も100%を超えて表示 - 執筆時間の計測 - チェックアウトまでの残り時間をカウントダウン - **文字設定** - フォントを選択可能 - ゴシック体 - メイリオ - 游ゴシック - 明朝体 - 本文文字サイズを14px～26pxの範囲で設定可能 - **保存・バックアップ** - ブラウザのlocalStorageによるデータ保存 - 本文入力時の自動保存 - 執筆中の定期的な自動保存 - 現在の作品または全作品のJSONバックアップ - JSONバックアップからのデータ復元 - 原稿のテキストファイル（.txt）書き出し - 保存容量が大きくなった場合の警告表示 - **キーボード・タッチ操作** - PCのマウス操作 - スマートフォンのタッチ操作 - Tabキーによる執筆画面内のフォーカス移動 - 執筆画面内でTab / Shift+Tabを循環 - Enter / Spaceによるフォーカス中のボタン操作 - モーダル表示中のフォーカストラップ - キーボードフォーカスの視覚的な表示 - **スマートフォン対応** - iPhone / iPad / Androidなどのソフトウェアキーボード表示に対応 - キーボード表示時に執筆エリアを自動的に縮小 - キーボード表示中も記号・Undo / Redoボタンを操作可能 - キーボード表示中は執筆に不要な操作部を一時的に非表示 - キーボードを閉じると通常の執筆画面に復帰 - スマートフォンのセーフエリアに対応 ## 使い方 1. ロビー画面の「＋ 新規プラン作成」から作品名、目標文字数、チェックイン日時、チェックアウト日時などを設定します。 2. 「原稿合宿を開始」を押して執筆画面へ移動します。 3. 執筆画面で本文を入力します。本文や設定は自動的に保存されます。 4. 必要に応じて記号ボタン、Undo / Redo、プロット・メモ、文字設定などを利用します。 5. 「txt書き出し」で原稿を書き出したり、「JSONバックアップ」で作品データを保存できます。 6. 保存したJSONバックアップは「全データ復元（JSON読み込み）」から復元できます。 ## データについて 作品データ、本文、プロット・メモ、文字設定などは、使用しているブラウザのlocalStorageに保存されます。 外部サーバーへ原稿を保存する仕組みではないため、ブラウザのデータ削除や端末変更などに備えて、必要に応じてJSONバックアップを取得してください。 保存容量が大きくなった場合は、画面上にバックアップを促す警告が表示されます。 ## 動作環境 Google Chrome、Safari、Firefox、Microsoft Edgeなどのモダンブラウザに対応しています。 PCおよびスマートフォンで利用できます。 スマートフォンでは、ソフトウェアキーボードを表示した状態でも執筆画面の操作を行えるよう最適化されています。 ## コンセプト **Web原稿合宿専用 かんづめの宿** 書くために、こもる。
