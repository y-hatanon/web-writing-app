# かんづめの宿

「かんづめの宿」は、執筆合宿をモチーフにしたブラウザ完結型の小説執筆・原稿管理Webアプリケーションです。
作品ごとに目標文字数やチェックイン・チェックアウト日時を設定し、旅館に滞在するような感覚で集中して原稿を書くことができます。

## 主な機能

### 作品管理

* 作品の新規作成・編集・削除
* 作品ごとの目標文字数設定
* チェックイン・チェックアウト日時の設定
* 作品一覧の並び替え（▲▼）
* 作品ごとのプロット・メモ保存

### 執筆エディタ

* ブラウザ上で本文を直接執筆
* Enterで「改行＋行頭全角スペース」を自動挿入

  * ただし、Enter直後の文字が「「」「『」「（」の場合は行頭全角スペースを挿入しない
* 「――」「……」「「」」「『』」「（）」の記号・括弧入力
* 行頭の全角スペースを考慮した記号入力
* 選択範囲を括弧で囲む操作
* 本文のUndo / Redo
* PCのキーボードショートカットによるUndo / Redo
* 本文のスペースを整理する「␣掃除」

  * スペースだけの行を空行にする
  * 行末の全角・半角スペースを削除
  * 行頭や行途中のスペースは変更しない

### 執筆状況

* リアルタイム文字数表示
* 目標文字数に対する進捗率表示
* 目標文字数を超えた場合も100%を超えて表示
* 執筆時間の計測
* チェックアウトまでの残り時間をカウントダウン

### 文字設定

* フォントを選択可能

  * ゴシック体
  * メイリオ
  * 游ゴシック
  * 明朝体
* 本文文字サイズを14px～26pxの範囲で設定可能

### 保存・バックアップ

* ブラウザのlocalStorageによるデータ保存
* 本文入力時の自動保存
* 執筆中の定期的な自動保存
* 現在の作品または全作品のJSONバックアップ
* JSONバックアップからのデータ復元
* 原稿のテキストファイル（.txt）書き出し
* TXT書き出し時は本文を加工せず、そのまま出力
* 保存容量が大きくなった場合の警告表示

### キーボード・タッチ操作

* PCのマウス操作
* スマートフォンのタッチ操作
* Tabキーによる執筆画面内のフォーカス移動
* 執筆画面内でTab / Shift+Tabを循環
* Enter / Spaceによるフォーカス中のボタン操作
* モーダル表示中のフォーカストラップ
* キーボードフォーカスの視覚的な表示

### スマートフォン対応

* iPhone / iPad / Androidなどのソフトウェアキーボード表示に対応
* キーボード表示時に執筆エリアを自動的に縮小
* キーボード表示中も記号・Undo / Redoボタンを操作可能
* キーボード表示中は執筆に不要な操作部を一時的に非表示
* キーボードを閉じると通常の執筆画面に復帰
* スマートフォンのセーフエリアに対応

## 使い方

1. ロビー画面の「＋ 新規プラン作成」から作品名、目標文字数、チェックイン日時、チェックアウト日時などを設定します。
2. 「原稿合宿を開始」を押して執筆画面へ移動します。
3. 執筆画面で本文を入力します。本文や設定は自動的に保存されます。
4. 必要に応じて記号ボタン、Undo / Redo、プロット・メモ、文字設定、「␣掃除」などを利用します。
5. 「txt書き出し」で原稿を書き出したり、「JSONバックアップ」で作品データを保存できます。
6. 保存したJSONバックアップは「全データ復元（JSON読み込み）」から復元できます。

## データについて

作品データ、本文、プロット・メモ、文字設定などは、使用しているブラウザのlocalStorageに保存されます。

外部サーバーへ原稿を保存する仕組みではないため、ブラウザのデータ削除や端末変更などに備えて、必要に応じてJSONバックアップを取得してください。

保存容量が大きくなった場合は、画面上にバックアップを促す警告が表示されます。

## 動作環境

Google Chrome、Safari、Firefox、Microsoft Edgeなどのモダンブラウザに対応しています。

PCおよびスマートフォンで利用できます。

スマートフォンでは、ソフトウェアキーボードを表示した状態でも執筆画面の操作を行えるよう最適化されています。

## 今後の機能予定

今後、より「原稿合宿所」として使いやすく、楽しく執筆できる場所にするため、以下の機能を検討しています。

### LittleDesk

* 執筆中の画面に置いて楽しめる小さなデスク環境
* 執筆を邪魔せず、合宿中の「自分の机」らしさを感じられる機能

### 達成スタンプ

* 目標文字数などの達成時にスタンプを獲得
* 合宿や執筆の達成記録を残せる仕組み
* 集めたスタンプを眺めたり、達成状況を確認できる機能

### 合宿ごとの執筆成果

* 合宿開始時からの文字数増加量を表示
* 今回の合宿で何文字書いたかを確認

### 執筆・合宿履歴

* 日ごとの執筆文字数を記録
* 過去の合宿ごとの執筆量や執筆時間を確認

### 1日の目標文字数

* 作品全体の目標とは別に、その日の執筆目標を設定
* 1日の目標に対する進捗を表示

### 滞在状態の表示強化

* 「未チェックイン」「滞在中」「チェックアウト済み」など、現在の合宿状態を分かりやすく表示

### チェックアウト時の合宿結果

* 合宿中の執筆文字数
* 執筆時間
* 目標達成率
* 合宿開始時からの文字数増加量
* などをまとめて確認

### 休憩・離席管理

* 執筆中の休憩や離席を記録・管理する機能を検討
