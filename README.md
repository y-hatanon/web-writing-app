# かんづめの宿

「かんづめの宿」は、執筆合宿をモチーフにしたブラウザ完結型の小説執筆・原稿管理Webアプリケーションです。

旅館にチェックインするような感覚で、作品ごとの執筆時間や目標文字数を設定し、集中して原稿を書くことができます。

## 主な機能

* **宿泊プラン形式の原稿管理**

  * 作品ごとに目標文字数を設定
  * チェックイン・チェックアウト日時を記録
  * 作品一覧の並び替えに対応

* **執筆エディタ**

  * 行頭の自動字下げ
  * Enterで「改行＋行頭全角スペース」を自動挿入
  * 「――」「……」「「」」「『』」「（）」などをワンタップで入力できる記号ボタン
  * 選択範囲を括弧で囲む操作
  * 本文のUndo / Redo
  * 通常のキーボード操作によるUndo / Redoにも対応

* **執筆状況の確認**

  * リアルタイム文字数表示
  * 目標文字数に対する進捗率表示
  * 執筆時間・残り時間の表示
  * 文字数達成時のポップアップ（ON/OFF切替可能）

* **プロット・メモ機能**

  * 作品ごとにプロットを保存
  * 執筆中の画面からプロットを確認・編集可能

* **データ保存・バックアップ**

  * ブラウザの `localStorage` による自動保存
  * JSON形式による全データのバックアップ・復元
  * テキストファイル（.txt）による原稿書き出し
  * ブラウザ上で完結するため、外部サーバーへの原稿保存は行わない

* **キーボード・タッチ操作**

  * マウス・タッチ操作に対応
  * Tabキーによる執筆画面内のキーボードナビゲーション
  * 執筆画面内でフォーカスを循環させるキーボード操作に対応
  * Enter / Spaceによるフォーカス中のボタン操作
  * iPhoneなどのスマートフォンでソフトウェアキーボードを表示した状態でも、執筆画面下部の記号・Undo / Redo操作を利用可能

* **表示設定**

  * フォント設定
  * 文字サイズ設定
  * スマートフォンのセーフエリアに対応

## 使い方

1. ロビー画面の「＋ 新規プラン作成」から作品名、目標文字数、チェックイン日時などを設定して合宿を開始します。
2. 執筆部屋で本文やプロットを入力します。
3. 本文はブラウザ上で自動保存されます。
4. 必要に応じて「txt書き出し」や「JSONバックアップ」で原稿・作品データを保存できます。
5. JSONバックアップから、保存した作品データを復元できます。

## データについて

作品データや本文は、基本的に使用しているブラウザの `localStorage` に保存されます。

そのため、ブラウザのデータを削除した場合などに備えて、必要に応じてJSONバックアップを作成してください。

## 動作環境

モダンブラウザ（Google Chrome、Safari、Firefox、Microsoft Edgeなど）のスマートフォン・PC環境に対応しています。

スマートフォンでは、ソフトウェアキーボード表示中の執筆操作にも対応しています。
